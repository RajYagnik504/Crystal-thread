# Crystal Thread ✦ Luxury Apparel & AI Virtual Trial Room

A bespoke luxury fashion e-commerce experience crafted with **Next.js 16 (App Router)**, **React 19**, **Three.js**, and **Tailwind CSS**.

---

## 🌟 Key Highlights & Features

- **✦ 3D Interactive Virtual Showroom:**
  - Zero-gravity garments suspended from an overhead luminous crystal thread.
  - Micro-breeze fabric sway with natural mouse cursor physics tilt and 360° on-demand rotation.
  - Lineup: European Flax Linen Shirts, Handloom Kurtas, Cotton-Linen Twill Bombers, Supima Tees, Organic Frocks, and Cozy Knit Hoodies.

- **✦ AI Virtual Trial Room (`/try-on`):**
  - Instant studio fitting preview on real editorial models & atelier mannequins:
    - 👨 Male Fashion Model
    - 👩 Female Fashion Model
    - 🧥 Male Tailor Mannequin
    - 👗 Female Tailor Mannequin
    - 🧒 Children’s Silhouette (with parental consent gate)
  - Interactive Before/After comparison slider with wave-ripple pulling knot.
  - Segmented View Mode Toggle: `[ ↔ Compare Slider ]` | `[ ✦ Tailored Fit ]` | `[ Base Model ]`.
  - Seamless 1:1 camera framing alignment across models and garments.

- **✦ Fabric Weaving Story (`Kids → Women → Men`):**
  - Dynamic luminous thread animation connecting collections.
  - Real fabric specification badges (GSM weight, GOTS organic certification, weave structure).
  - 1-click launch into the trial room for any piece.

- **✦ Physical Atelier Store Integration:**
  - **Location:** Sateshwar, Tilak Nagar, Auraiya, Uttar Pradesh – 206122, India.
  - **Direct Line:** +91 93890 05539 (Call & WhatsApp Concierge).
  - **Verified Rating:** ★ 4.6 / 5.0 (11 Verified Google Reviews).

- **✦ Admin Product & Inventory Dashboard (`/admin`):**
  - Dedicated portal to add and manage kids' and adults' apparel.
  - Real-time product card preview with category, age groups (2-4, 5-8, 9-12), price, and fabric details.
  - Instant filesystem persistence to `products.json`.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 16.4.3 (App Router, Webpack engine)
- **Language:** TypeScript 5
- **3D Graphics:** Three.js 0.186
- **Animations:** GSAP & Lenis smooth scrolling
- **Styling:** Tailwind CSS 4
- **State Management:** React 19 Hooks

---

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### 3. Production Build
```bash
npm run build
npm run start
```
